# Coding Standards

**Purpose:** This file is for defining the technical rules, preferred libraries, formatting, and naming conventions. AI agents read this to ensure their code matches your style.

## Language & Framework
- Language: Java (Version [e.g., 17])
- Build Tool: Gradle

## Rules
- **Naming:** [e.g., Use camelCase for variables, PascalCase for classes. Interface names should NOT start with 'I'.]
- **Libraries:** [e.g., Prefer standard Java `java.nio` over third-party IO libraries. Use Jackson for JSON.]
- **Error Handling:** [e.g., Always throw custom exceptions instead of generic RuntimeExceptions. Log all errors using SLF4J.]
- **Documentation:** [e.g., Add Javadoc comments to all public methods.]
