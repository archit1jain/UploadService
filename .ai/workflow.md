# Agent Workflow

**Purpose:** This file is for teaching the AI agent how to interact with your codebase, run tests, and verify its own work.

## Build Instructions
To build the project, always run:
`./gradlew build`

## Testing Instructions
Before finalizing a fix, run tests using:
`./gradlew test`
